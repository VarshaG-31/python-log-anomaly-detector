# 🔍 Python Log Anomaly Detector

## 📌 Project Overview

Python Log Anomaly Detector is a Python-based application
that analyzes log files and identifies potential issues.

It helps users understand application logs by summarizing
errors, warnings, critical events, and security alerts.

## ✨ Features

- Upload custom log files.
- Analyze server, database, and security logs.
- Count INFO, WARNING, ERROR, and CRITICAL events.
- Visualize log levels using charts.
- Identify frequently occurring errors.
- Detect repeated failed login attempts.
- Display log entries in an interactive dashboard.

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly

## 📂 Project Files

- `app.py` - Interactive dashboard.
- `main.py` - Log analysis functionality.
- `server.log` - Sample server logs.
- `database.log` - Sample database logs.
- `security.log` - Sample security logs.
